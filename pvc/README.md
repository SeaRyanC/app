## PVC - Parametric Vase Creator

Design a vase by writing plain JavaScript. Define `diameter(z, theta)` for the inner diameter at the wall's midpoint line and `thickness(z, theta)` for how far the wall extends outward from it, plus any helper functions you like. Set the z range, z step, and theta step, and watch the result update in a 3D preview you can orbit, pan, and zoom.

Your code and settings are saved in your browser, and mistakes in your code are reported inline while the preview keeps the last valid shape. When you're happy, export the vase as a binary STL for 3D printing.
